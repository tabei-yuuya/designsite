# Visual Design System (DESIGN.md)

本ファイルは、AIエージェントがUIコード（HTML, CSS, React, など）を生成する際に参照するデザイン仕様書です。UIを構築する際は、必ずこのルールに従ってください。

参照モデル: ブランディング／クリエイティブスタジオ系のコーポレートサイト（フルブリード映像 × 巨大タイポグラフィ × 極細ライン）。
対象サイト: 1ページ構成の個人ポートフォリオ（HERO / ABOUT / WORKS / CONTACT / FOOTER）。

## 1. トーン＆マナー

- **ブランドイメージ:** ミニマル、エディトリアル、シネマティック。無彩色を基調とした静かで上質な世界観。
- **コアバリュー:** ビジュアル（写真・映像・制作実績）を主役にし、UIは極力「存在を消す」こと。情報は少なく、余白とタイポグラフィの大きさの対比で語る。
- **キーワード:** 大胆な見出し / 細い罫線 / 小さく控えめなナビ / 無彩色 / 1色だけの差し色
- **禁止事項:** 派手なグラデーション、ドロップシャドウの多用、角丸の大きいポップなカード、絵文字、多色使い、本ファイルに定義のない色コードの直書き。

## 2. カラーパレット (Colors)

色は必ず下記の CSS 変数で参照すること。**ここに無い色コードを新たに使ってはいけない。** 基本はダークテーマ。

### 2-1. ダーク面（基本）

| 変数名 | 値 | 用途 |
|---|---|---|
| `--color-bg` | `#0F1012` | ページ背景（ほぼ黒） |
| `--color-surface` | `#1A1B1D` | ヘッダー（スクロール後）、フローティングナビ、フッター、モバイルメニュー |
| `--color-surface-raised` | `#232324` | 画像なし時のカード面、画像プレースホルダー |
| `--color-bg-alt` | `#2C2C2D` | セクション切り替え用の代替背景 |
| `--color-text` | `#F2F2F0` | 本文・見出し（オフホワイト） |
| `--color-text-muted` | `#9C9C9A` | キャプション・補足・英字ラベル |
| `--color-text-display-muted` | `#B5B5B3` | 大見出しを控えめに見せたい場合のみ |
| `--color-border` | `rgba(255, 255, 255, 0.16)` | 罫線・境界線 |
| `--color-overlay` | `rgba(0, 0, 0, 0.45)` | 写真・動画の上に敷く暗幕 |

### 2-2. ライト面（明るいセクション用）

| 変数名 | 値 | 用途 |
|---|---|---|
| `--color-bg-light` | `#EEEFF0` | ライトセクション背景 |
| `--color-text-on-light` | `#4A463F` | ライト面の本文 |
| `--color-text-muted-on-light` | `#66665F` | ライト面の補足・ラベル |
| `--color-border-on-light` | `rgba(0, 0, 0, 0.14)` | ライト面の罫線 |
| `--color-focus-on-light` | `#1A1B1D` | ライト面でのフォーカスリング |

### 2-3. アクセント

| 変数名 | 値 | 用途 |
|---|---|---|
| `--color-accent` | `#A6D43A` | ライムグリーン。ロゴ・ダーク面のフォーカスリング・アクティブ状態・状態ドットのみ。面積は画面の1%以下 |

- アクセントは**ダーク面でのみ**使う（ライト面ではコントラスト 1.5:1 しか取れないため使用禁止）。
- アクセントを文字色として本文に使わない。
- **状態ドット:** `--color-accent` の直径 `6px` の丸（稼働中・対応可などの表示）。

### 2-4. 検証済みコントラスト比（参考）

| 組み合わせ | 比率 |

| `--color-text-muted` on `--color-bg` | 6.92:1 |
| `--color-text-muted` on `--color-surface` | 6.27:1 |
| `--color-text-muted` on `--color-bg-alt` | 5.07:1 |
| `--color-text-on-light` on `--color-bg-light` | 8.15:1 |
| `--color-text-muted-on-light` on `--color-bg-light` | 5.02:1 |
| `--color-accent` on `--color-bg` | 10.97:1 |
| `--color-focus-on-light` on `--color-bg-light` | 14.97:1 |

## 3. タイポグラフィ (Typography)

### 3-1. フォントファミリー

| 変数名 | 値 | 読み込むウェイト |
|---|---|---|
| `--font-ja` | `"Noto Sans JP", "Hiragino Sans", sans-serif` | 400 / 700 |
| `--font-ja-serif` | `"Shippori Mincho", "Noto Serif JP", "Hiragino Mincho ProN", serif` | 400 |
| `--font-en` | `"Geist", "Helvetica Neue", Helvetica, Arial, sans-serif` | 300 / 400 |
| `--font-display` | `"Archivo", "Helvetica Neue", sans-serif`（太字・幅広のグロテスク） | 700 |

- 上記以外のウェイトは読み込まない。Google Fonts から読み込み、`display=swap` を付ける。
- `<link rel="preconnect">` を `fonts.googleapis.com` と `fonts.gstatic.com` に対して設定する。

### 3-2. サイズ

| 要素 | 指定 |
|---|---|
| ベースフォントサイズ | `16px` (1rem) |
| ディスプレイ (Hero見出し) | `clamp(2.5rem, 11vw, 10rem)`, `line-height: 0.9`, `font-weight: 700`, `letter-spacing: -0.03em`, 英大文字, `--font-display` |
| 見出し 1 (h1) | `clamp(2.5rem, 5vw, 4.5rem)`, `line-height: 1.05`, `font-weight: 400`, `letter-spacing: -0.02em` |
| 見出し 2 (h2・セクション見出し) | `clamp(1.75rem, 3vw, 2.5rem)`, `line-height: 1.2`, `font-weight: 400` |
| 本文 (p) | `1rem`, `line-height: 1.8`（日本語）/ `1.5`（英語） |
| ラベル・ナビ (英字) | `0.8125rem` (13px), `letter-spacing: 0.12em`, 大文字, `--color-text-muted` |
| ラベル・ナビ (日本語) | `0.875rem` (14px), `letter-spacing: 0.4em` |
| キャプション | `0.75rem` (12px), `line-height: 1.6`, `--color-text-muted` |
| カテゴリーラベル | `0.75rem` (12px), `--font-ja`（ゴシック）, `--color-text-muted`。タイトルの直上に `8px` 空けて置く |
| 事例タイトル (英字) | `clamp(1.25rem, 1.6vw, 1.5rem)`, `font-weight: 400`, 大文字, `letter-spacing: 0.02em` |
| 事例リード (日本語) | `1.0625rem` (17px), `--font-ja-serif`, `line-height: 1.8`, `letter-spacing: 0.12em` |
| 数値表示 (Data) | 数値 `2rem` `font-weight: 300` `letter-spacing: -0.02em` `--font-en`。単位（項目、h、% 等）は `0.5em` に縮小して数値の直後に並べる |

- **最小文字サイズは 12px。** これより小さい文字は使わない。
- **補助表記:** 英字ラベルは `( About )` のように丸括弧＋前後スペースで囲む。セクション番号は `02 // 04` 形式。

## 4. スペースとレイアウト (Spacing)

4px を基本単位とし、下記のトークンのみを使うこと。

| 変数名 | 値 | 主な用途 |
|---|---|---|
| `--space-0` | `4px` | 最小の調整 |
| `--space-1` | `8px` | ラベルとタイトルの間など |
| `--space-2` | `16px` | 標準的な余白 |
| `--space-3` | `24px` | カード間の gap、タイトルとリードの間 |
| `--space-4` | `32px` | 要素グループ間 |
| `--space-5` | `48px` | 大きめのブロック間 |
| `--space-6` | `64px` | 大きな余白 |
| `--space-7` | `96px` | カードグリッドの行間 |
| `--space-8` | `128px` | セクション間（モバイルは `--space-7`） |

### 4-1. コンテナ

- **ページ左右マージン (`--page-gutter`):** デスクトップ `56px` / タブレット `32px` / モバイル `20px`
- **コンテナ最大幅 (`--container-max`):** `1440px`。これを超える画面では中央寄せ。フルブリード画像・動画は例外として画面幅いっぱいに広げてよい。
- **本文の最大幅 (`--measure`):** `680px`（日本語で1行およそ40字）。本文段落はこれより広げない。

### 4-2. グリッド・配置

- **レイアウト方式:** CSS Flexbox または CSS Grid を使用すること。
- **グリッド:** 12カラム。カラム境界に極細の縦横罫線（`--color-border`, `1px`）を見せるレイアウトを許容する。罫線の交点には直径 `6px` のドット（`--color-border` と同じ明るさの塗り）を置いてよい。
- **配置原則:** Hero では画面の四隅（左上ロゴ・右上ナビ・左下クレジット・右下スクロールインジケーター）に小さな情報を分散配置し、中央は画像と見出しに明け渡す。

### 4-3. セクション構成

- **HERO:** `min-height: 100svh`。背景はフルブリードの写真または動画（`object-fit: cover`）＋ `--color-overlay`。中央〜左下にディスプレイ見出し。
- **ABOUT:** 左に英字ラベル＋h2、右に本文（`--measure` 以内）の2カラム。その下に「3つの強み」を3カラムで並べる。各強みは「数値表示（例: `46` 項目）→ 見出し → 説明文」の順で、各ブロックの上に `1px` 罫線。
- **WORKS:** 事例カード（5章）のグリッド。デスクトップ3列 / タブレット2列 / モバイル1列、`gap: var(--space-3)`、行間 `var(--space-7)`。
- **CONTACT:** 左に大見出しと稼働時間などの補足、右にフォーム（5章）。
- **フッター:** フルブリード画像または `--color-surface` を背景に、左下に大見出し（`clamp(2.5rem, 5vw, 5rem)`、`font-weight: 400`）、右側にリンクリスト（行間 `var(--space-5)`、`0.875rem`）＋ CTA ボタン ＋ SNSアイコン。最下部に `1px` 罫線で区切ったコピーライト行（左: ©、右: クレジット、`0.8125rem` `--color-text-muted`）。

## 5. コンポーネントスタイル (Components)

### ナビゲーション

ナビは**画面幅とスクロール位置に応じて次の3状態のいずれか1つだけ**を表示する。同時に2つ以上表示してはいけない。

| 画面幅 | スクロール位置 | 表示するナビ |
|---|---|---|
| デスクトップ (1024px〜) | ページ最上部（Hero 内） | ヘッダー |
| デスクトップ (1024px〜) | Hero を過ぎた後 | フローティングナビ |
| タブレット・モバイル (〜1023px) | 常時 | ハンバーガーボタン＋全画面メニュー |

- **ヘッダー (Header):**
    - 高さ `80px`、`position: absolute`、背景は透明（Hero の暗幕の上に載る）
    - 左にロゴ、右にナビ項目（ABOUT / WORKS / CONTACT）。項目間 `var(--space-4)`、英字ラベルの書式
    - Hero 上ではナビ文字を `--color-text` にする（動画上で Muted は読みにくいため）
    - 下端に `--color-border` の `1px` 罫線
    - 現在表示中のセクションの項目に `1px` のアンダーライン（`aria-current="true"`）
- **フローティングナビ (Floating Nav):**
    - Hero の下端を過ぎたら表示し、ヘッダーはスクロールで画面外へ流れる。上に戻り Hero に入ったら非表示
    - 画面上部中央に `position: fixed`、上端から `var(--space-2)`。幅 `500px`、高さ `64px`、背景 `--color-surface`、角丸 `4px`、`1px solid var(--color-border)`
    - 左にメールアイコン（CONTACT へのリンク）、中央にロゴ（ページ先頭へのリンク）、右にナビ項目（ABOUT / WORKS / CONTACT）
    - 表示・非表示は `opacity` + `translateY(-8px)` を `300ms ease` で変化
    - アイコンは線幅 `1.5px`、`24px`。アイコンのみのリンクには `aria-label` を付ける
- **ハンバーガーメニュー (Mobile / Tablet):**
    - 右上に `position: fixed` のメニューボタン（二本線アイコン、タップ領域 `48px × 48px`、背景 `--color-surface`、角丸 `4px`）。左上のロゴはスクロールで流れてよい
    - ボタンは `<button aria-expanded aria-controls>` で実装し、開くと二本線が `×` に変わる
    - メニューは全画面オーバーレイ（背景 `--color-bg`）。項目を縦に並べ、h1 サイズの英字＋小さい日本語ラベル
    - 開いている間は背面のスクロールを止め、フォーカスをメニュー内に閉じ込める。`Esc` キーと項目のタップで閉じる
    - 開閉は `opacity` を `300ms ease` で変化

### ボタン (Button)

- 角丸 `2px`、パディング 縦 `12px` 横 `20px`
- 背景 `rgba(255, 255, 255, 0.10)` + `backdrop-filter: blur(8px)`
- 文字 `0.875rem`、`--color-text`、`font-weight: 400`
- シャドウ なし
- ホバー時: 背景を `rgba(255, 255, 255, 0.18)` にし、`transition: 200ms ease`。移動・拡大はしない
- 外部リンクのボタンは右側に `↗` を付ける

### テキストリンク (Link)

- **本文中のリンク:** `--color-text` ＋ `1px` の下線（`text-underline-offset: 0.2em`）。色だけで区別しない
- **ナビ・フッターなど単独で並ぶリンク:** 下線なしでよい
- ホバー: `opacity: 0.7`、または下線 `1px` を左から伸ばすアニメーション
- 外部リンクは右側に `↗` を付け、`target="_blank" rel="noopener"` を指定する

### 事例カード (Work Card)

- 構成: 画像（サイトのファーストビューのスクリーンショット、`aspect-ratio: 16 / 10`、画像なしは `--color-surface-raised` のベタ面）→ カテゴリーラベル → 英字タイトル → 日本語リード → 右下に `↗` 矢印
- 画像とテキストの間 `var(--space-4)`、タイトルとリードの間 `var(--space-3)`
- 角丸 `0px`、枠線・背景・影なし。画像のみ `1px solid var(--color-border)` の枠を付けてよい（暗いサイトの画像が背景に溶けるのを防ぐため）
- カード全体を1つのリンク（外部サイトへ）にする
- ホバー: 矢印を `translateX(4px)`、画像を `scale(1.03)`、`transition: 600ms cubic-bezier(0.2, 0.8, 0.2, 1)`（画像は `overflow: hidden` の枠内で拡大）
- 作品画像にはグレースケール処理をかけない

### 強みブロック (Strength)

- ABOUT 内で使用。上に `1px` 罫線、パディング上 `var(--space-4)`
- 構成: 英字の番号ラベル（`01`）→ 数値表示（例: `46` + `項目`）→ 日本語見出し（`1.125rem`、`font-weight: 700`）→ 説明文（`0.875rem`、`line-height: 1.8`）
- 数値が無い強みは、数値の代わりに英字の短いキーワード（`1.5rem`、`--font-en` 300）を置く

### フォーム (Contact Form)

- ラベルは入力欄の上に置き、`0.875rem` `--color-text`。必須項目はラベル末尾に `（必須）` と文字で表記
- 入力欄: 背景 透明、枠は下辺のみ `1px solid var(--color-border)`、パディング 縦 `12px`、文字 `1rem`
- textarea: 最小高さ `160px`、`resize: vertical`
- フォーカス時: 下辺を `--color-text` の `2px` にする（フォーカスリングも表示）
- プレースホルダーは入力例のみに使い、ラベルの代わりにしない
- **エラー表示:** 赤などの色は使わない。入力欄の下辺を `--color-text` の `2px` にし、欄の直下に `※ メールアドレスの形式が正しくありません` のような文言を `0.875rem` `--color-text` で表示。`aria-invalid="true"` と `aria-describedby` でエラー文と紐づける
- 送信ボタンはボタンスタイルに従い、送信中は `disabled` にして文言を「送信中…」に変える。送信完了メッセージはフォームの位置に表示し、`role="status"` を付ける

### スクロールインジケーター

- Hero の右下に縦書きの `Scroll`（12px、`--color-text-muted`）＋ 直径 `24px` の円形ボタン（背景動画の再生/一時停止）
- ボタンには `aria-label="背景動画を一時停止"` / `"背景動画を再生"` を状態に合わせて付ける

### VIEW カーソル（任意）

- 事例画像ホバー時、カーソル位置に直径 `72px` の半透明白円（`rgba(255, 255, 255, 0.85)`、`backdrop-filter: blur(4px)`）と `VIEW` テキスト（`0.75rem`、`letter-spacing: 0.1em`、`--color-surface`）を追従表示
- ネイティブのカーソルは消さない。タッチデバイスと `prefers-reduced-motion: reduce` 時は表示しない

## 6. レスポンシブ振る舞い (Responsive)

- **モバイルファースト**で記述すること（基本スタイルはモバイル、`min-width` のメディアクエリで拡張する）。
- **ブレイクポイント:**
    - スマホ (Mobile): `〜 639px`
    - タブレット (Tablet): `640px 〜 1023px`
    - デスクトップ (Desktop): `1024px 〜`
- **ナビ:** 5章の表に従う（デスクトップ＝ヘッダー → フローティングナビ、タブレット以下＝ハンバーガーのみ）。
- **Hero:** 四隅配置の情報は縦に積み、見出しの下へ移動。ディスプレイ見出しは `clamp()` で縮小し、単語の途中で折り返さない（`overflow-wrap: normal`、`word-break: keep-all`）。
- **グリッド罫線:** モバイルでは縦罫線を非表示にし、横罫線のみ残す。
- **ABOUT:** タブレット以下は2カラムを縦積み。強みブロックはタブレット以下で1列。
- **事例カード:** デスクトップ3列 / タブレット2列 / モバイル1列。
- **CONTACT:** タブレット以下は見出し → フォームの縦積み。
- **CTA ボタン (Mobile):** 幅 `100%`、高さ `48px`、左寄せテキスト＋ `↗`。
- **セクション間の余白:** モバイルは `var(--space-7)`、タブレット以上は `var(--space-8)`。

## 7. アクセシビリティ (Accessibility)

- すべてのテキストは背景色とのコントラスト比を `4.5:1` 以上にすること（2-4 の表を参照。新しい組み合わせを作る場合も同じ基準）。
- 写真・動画の上にテキストを載せる場合は、`--color-overlay` またはグラデーションの暗幕を必ず敷くこと。
- 画像には必ず `alt` 属性を記述すること。事例画像は `alt="〇〇株式会社 コーポレートサイトのトップページ"` のように内容を書く。装飾画像は `alt=""`。
- 背景動画は `autoplay muted loop playsinline` とし、一時停止ボタンを必ず設置する。
- **フォーカス表示:** ダーク面では `--color-accent`、ライト面では `--color-focus-on-light` の `2px` アウトライン（`outline-offset: 3px`）。`:focus-visible` で表示し、アウトラインを消さない。
- タップ領域は最小 `44px × 44px`。
- 見出しレベル（h1 → h2 → h3）を飛ばさない。h1 はページに1つ（Hero の見出し）。
- `prefers-reduced-motion: reduce` の場合は次をすべて無効化する: 背景動画（ポスター画像に差し替え）、フェードイン、画像の `scale`、VIEW カーソル、ナビの移動アニメーション（`opacity` の切り替えのみ残してよい）。

## 8. エージェントプロンプトガイド (Agent Prompt)

AIエージェントへの指示です。コードを生成する際は、以下のルールを遵守してください。

1. 色・余白・フォントは 2〜4章で定義した CSS 変数名をそのまま使い、`:root` にまとめて宣言すること。値を直書きしないこと。
2. 日本語が不自然にならないよう、文字間隔（`letter-spacing`）や行間を適切に調整してください。改行を言葉の途中でしないようにしてください（`word-break: keep-all`、`text-wrap: pretty` を使用。見出しには `text-wrap: balance`）。
3. 本ファイルに無いデザイン要素を生成する場合は、事前にユーザーに質問するか、このデザインシステムに準拠した形で提案してください。
4. 色数を増やさないでください。無彩色 + `--color-accent` 1色のみで構成してください。
5. 画像素材がない場合は、`--color-surface-raised` のプレースホルダーに「hero video」「work thumbnail」などの説明ラベルを入れてください。
6. 写真はモノクロ〜低彩度で統一し、トーンが揃わない場合は `filter: grayscale(1) contrast(1.05)` で調整してください（作品画像は除く）。
7. アニメーションは控えめに。フェードイン（`opacity` + `translateY(16px)`、`800ms`、一度だけ）を基本とし、バウンスや回転は使用しないでください。
8. ナビゲーションは 5章の表のとおり、同時に1種類だけを表示してください。
