Branding

ブランディング

理念や強みを言語化し、ロゴ・トーン・ガイドラインまで一貫したブランドの形をつくります。

main visual
( Overview )

“らしさ”を、
伝わる形に。

ブランドは、ロゴや色だけで成り立つものではありません。企業の考え方や強み、お客様との約束が、あらゆる接点で一貫して伝わってはじめて形になります。

ヒアリングとワークショップで本質を整理し、言葉とビジュアルの両面からブランドを設計。社内外で使い続けられるガイドラインまでご用意します。

( Issues )

こんな課題に

  • 01会社の強みや想いを、うまく言葉にできていない
  • 02ロゴや名刺、Webサイトの印象がばらばらになっている
  • 03事業の成長に、ブランドの見え方が追いついていない
  • 04社内で共有できるデザインの基準がない
( Scope )

提供内容

  • ヒアリング・ワークショップ事業の強みや想いを言葉にします。
  • ブランドコンセプト軸となる考え方と言葉を定めます。
  • ロゴデザインコンセプトを象徴するロゴを制作します。
  • カラー・書体の設計一貫した印象をつくる基準を決めます。
  • ブランドガイドライン社内外で使えるルールをまとめます。
  • ツール展開名刺やWebなど各接点へ展開します。
